# tori — LLMs and Human Discussion Analysis

[English](#english) | [日本語](#日本語)

---

## English

A collection of experiments on large language models (LLMs) and argument graphs in the
Argument Interchange Format (AIF / IAT).
Each experiment lives in its own folder and can be reproduced on its own: the code, prompts,
aggregated metrics and report for an experiment are all kept in that folder.

| Folder                                 | Contents                                                                                   |
| -------------------------------------- | ------------------------------------------------------------------------------------------ |
| [`aif-with-llm/`](aif-with-llm/) | Accuracy evaluation of AIF argument graph extraction by LLMs (QT30; TJ-SIF 2026 paper experiments) |

See the README in each folder for how to run the experiment, how the data is handled, and the license.

---

## 日本語

大規模言語モデル（LLM）と Argument Interchange Format（AIF / IAT）の議論グラフに関する実験をまとめたリポジトリ。
実験ごとにフォルダを分け、それぞれが独立に再現できるようにしている（コード・プロンプト・集計値・レポートを各フォルダに置く）。

| フォルダ                               | 内容                                                                    |
| -------------------------------------- | ----------------------------------------------------------------------- |
| [`aif-with-llm/`](aif-with-llm/) | LLM による AIF 議論グラフ抽出の精度評価（QT30、TJ-SIF 2026 論文の実験） |

各実験の実行方法・データの扱い・ライセンスは、それぞれのフォルダの README を参照。
